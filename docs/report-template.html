How it works

Input → Validation → Decision → Evidence

The saved study uses 20 simulation replications, 30 products, and 104 weekly rounds. Counterfactual demand at unobserved prices is simulated, not measured in a client rollout.

The loop improves on the static policy by 2.69 percentage points on average, while remaining 0.52% below unchanged prices on average. A relative improvement is not an absolute commercial gain.

Observational price-demand association does not by itself identify a causal elasticity. The oracle is an information-advantaged simulation comparator.
